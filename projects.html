Side Scroller Game

Technologies: JavaScript · p5.js

This is a side scroller game that I created from scratch. From initial sketch designs to coding finalisation was all done by me.

First, I created the background and game character based on the initial design. After that I coded the movement for the main character and the places for the platforms.

When this was done, I focused on creating the enemy, end point and tokens. The top left corner on the screen contains the amount of lives left and the amount of tokens collected.

Maze Quiz

Technologies: Python · Turtle


This is a maze-based quiz game that I created using Python and the Turtle graphics library. The player navigates through a maze while answering quiz questions and collecting coins.

I implemented the player's movement, collision detection, quiz questions, collectables, lives and different game states including the start screen, gameplay, game over and completion states.

The project helped me develop my understanding of Python programming, game logic and managing different states within an interactive application.
